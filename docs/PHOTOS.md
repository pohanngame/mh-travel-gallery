# 成员照片放置说明

把成员照片放进 **`public/photos/`**，文件名与 `src/data/studio.js` 里 `members` 的 `id` 保持一致：

| 文件名 | 对应成员 |
| --- | --- |
| `muhetaer.jpg` | 木合塔尔（负责人） |
| `liangyuying.jpg` | 梁玉莹 |
| `zhengyilun.jpg` | 郑益伦 |

然后在 `src/data/studio.js` 里把该成员的 `photo` 字段填上路径：

```js
photo: '/photos/muhetaer.jpg',
```

`photo` 留空时，卡片显示该成员姓氏的大号衬线图章，不会出现破图。

## 成员照必须先裁成 4:5

卡片头像区是固定 **4:5** 竖版。照片**在入库前就裁成 4:5**（例如 820×1025），
不要指望 `object-fit: cover` 在浏览器里替你构图——它只会从中间切，
切点落到脸上时页面里没有任何办法救回来。

裁的时候只有一个标准：**主题人物的脸完整，头顶可以少**。
实在做不到时（原图是多人合影、人脸贴着画面边），按这个顺序让步：
先保住主角的脸，再决定同框的人是留还是切。

**同框的人要不要留，看它是不是本人的一部分。**

- 如果是**别人的单人照**（合影里的旁人、路人），裁掉——访客分不清第二个人是谁，那是信息错误；
- 如果是**本人参与的合影/自拍**（工坊活动、和同伴一起），**留住**。一张只有半张脸贴边的合影，
  仍然在说「那天我们在一起」；把它裁成单人特写，等于把那件事删了。

| 文件 | 出处 | 裁切 |
| --- | --- | --- |
| `muhetaer.jpg` | 900×1125 | 4:5，近景头像 |
| `liangyuying.jpg` | 820×1025 | 4:5，两人自拍，同框的同伴保留（他在右缘，只入镜一部分） |
| `zhengyilun.jpg` | 640×800 | 4:5，海边坐姿，保留上半身 |

**梁玉莹那张的取舍**：源图 1706×1279（4:3），她的脸横跨 x 40–810，旁边那位从 x 780 开始。
4:5 窗口在 1279 的高度下最宽只能到 1023——**两个人加起来的横向跨度 1420 永远塞不进去**，
所以「两人都完整」在这张图上无解，只能选切谁：切她（40–200 的左脸颊）或切他（192px 之后的部分）。
选择切他：她是这张卡的主角，他作为「同框的人」被右缘吃了大半张脸，但眼睛、鼻子、嘴角都在——
读起来就是一张真实的自拍，而不是裁切事故。想让他完整入镜，只有换一张两人离得松一点的合影。

单张 ≤ 300KB（jpg 质量 88 导出即可）。

## 工坊合影（关于区块档案卡）

| 文件名 | 用在哪 |
| --- | --- |
| `workshop.jpg` | 关于区块「工坊档案卡」的照片位 |

**先裁成 3:2 再放进来**（例如 1200×800），不要把原图直接丢进来靠 CSS 裁：
照片位是 3:2，原图比 3:2 宽时，`object-fit: cover` 会把两侧各切掉一截，切点常常
正好落在照片里的人物或文字上。裁的时候留**横幅标题 + 人**，两侧的单位名单可以整块舍掉。

当前这张：2025.10 金砖赛区块链应用开发与运维赛项闭幕式合影，
1200×800 / q86 / 155 KB，源图 1920×995 居中裁切后缩放。
换图后记得同步 `studio.js` 里的 `photoAlt` 与 `photoCaption`（说明写赛事与场次，不写「合影」二字）。
